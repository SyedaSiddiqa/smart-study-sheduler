# smart-study-sheduler
A single-file, client-side web application that helps students plan exam study sessions by resolving overlapping time blocks using classical scheduling algorithms. Implements three strategies — Greedy Interval Scheduling (max sessions), Weighted Interval Scheduling via Dynamic Programming (max priority), and Interval Partitioning (zero sessions dropped, minimum tracks). Features a dark-themed responsive UI with a live Gantt timeline, priority tagging (P1–P4), conflict detection, and a one-click TXT export of the generated plan. No dependencies, no build step — just open in a browser.
